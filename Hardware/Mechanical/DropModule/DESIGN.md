# 投放模块 · 设计说明

> 记录这套机构**为什么是现在这个样子**。
> 装配步骤、接线、排查见 `README.md`；交互演示见 `demo.html`。

---

## 一、要解决什么问题

无人艇要完成"抵达落水点 → 放下救生圈"。船端软件链路早就通了
（`servo_release.c` 驱动 GPIO6 的 MG90S，网页有二次确认，桥接板对释放帧立即转发），
缺的是**能真正把救生圈放出去的机构**。

约束条件：

| 约束 | 数值 | 为什么重要 |
| :--- | :--- | :--- |
| 执行器 | 只有 MG90S，一个 | 不能再加舵机 |
| 舵机扭矩 | 1.8 kg·cm @4.8V | 只能做"脱扣"，不能承力 |
| 行程 | 0~180°，可用 0~120° | 不需要高精度，但要有余量 |
| 断电行为 | 必须保持锁定 | 掉电不能把救生圈丢了 |
| 载荷 | 100~300 g 救生圈 | 决定力臂和受力 |
| 空间 | 船头，下方是水面 | 决定托板必须外伸 |

核心设计哲学：**舵机不做功，只做"改变约束状态"**。
它不推、不拉、不提载荷，只是让开一个位置。

## 二、最终方案

### 机构构成

```
                    俯视（从上往下看）

   船内 ┌──────────────────┐
        │   支架 ▣ 舵机     │
        │       ○ 输出轴    │ ← 轴竖直朝上
        │        ╲          │
        │         ● 销轴    │ ← 摇臂带一根竖直销轴，绕轴摆
        │        ╱          │
        │   ╭───╯           │
        │   │  耳板（带开口缺口）
   船外 │   │               │
        └───┴───────────────┘
             │
            托板（承载，前端伸出船外）
```

```
                    侧视（载荷怎么被挡住）

   托板 ──────────────┐
                      │ 倒扣圆盘 Ø12 ── 挡住"托板往上逃"
                   ╔══╪══╗
                   ║  │  ║   耳板 ────── 被销轴挡住"往前翻"
                   ╚══╪══╝
                      │ 销轴 Ø5
                   ┌──┴──┐
                   │MG90S│
                   └─────┘
```

### 三个零件各管一件事

| 零件 | 管什么 | 如果去掉会怎样 |
| :--- | :--- | :--- |
| 销轴（Ø5，距轴 15 mm） | 挡住耳板的**水平**位移 | 托板直接被载荷压翻，救生圈自己掉 |
| 倒扣圆盘（Ø12） | 挡住耳板的**竖直**逃逸 | 托板沿销轴往上滑脱，销轴形同虚设 |
| 弹簧 | 断电时把摇臂压在锁定位 | 掉电后销轴被振动带开，载荷丢失 |

**三个缺一不可。** 第二项是最隐蔽的 —— 见第四节。

## 三、力学账（为什么能投 300 g）

### 力臂换算

```
载荷重心距铰链   28.0 mm
反力点(缺口)距铰链 10.5 mm
                      ↑
载荷 300 g  →  圆盘承受 7.84 N 竖直力
舵机需提供  →  0.012 N·m（占堵转 7%）
```

### 各环节承载能力

| 环节 | 能力 | 300 g 时占用 |
| :--- | :--- | :--- |
| 销轴 Ø5 抗剪（双剪） | ≈ 982 N | 0.8% |
| 倒扣圆盘 M2 螺丝拔出 | ≈ 30~50 N | 16~26% |
| 舵机输出轴径向承载 | ≈ 10 N (1 kgf) | 78% ← **瓶颈** |

**结论：载荷上限约 375 g，由舵机输出轴的径向承载决定。**
建议工作载荷 ≤ 188 g（留 2 倍余量）。

销轴和螺丝的抗剪能力远超需求，真正受限的是"MG90S 的轴不能承受太大侧向力"。
这也解释了为什么不能把铰链移得更近 —— 力臂小，圆盘受力会成倍放大。

## 四、三次失败的方案（这部分最有价值）

前三个版本都是在**几何扫描**时才发现不可行。肉眼看模型完全看不出来。

### v1 摆臂挂钩：下翻必然切进底板

**做法**：舵机挡块压住摆臂内侧，载荷挂在臂端。舵机挡块让开，摆臂下翻。

**失败原因**：摆臂要**向下**翻，而它的内侧必然位于底板正上方。
绕支点下翻时，内侧会扫进底板。

**验证方式**：按 10800 组参数搜索（舵机位置 × 支点位置 × 臂长 × 凸台高度），
可行解 **0**。

**结论**：这不是调参能解决的，是**形式**问题。承重侧必须延伸到船体外、
下方是空水面，约束才会消失。

### v2 竖直挡块压短杆：复位扫掠无解

**做法**：舵机竖直装，挡块压在托板尾部的配重短杆上。挡块让开，短杆抬起，托板前翻。

**失败原因**：锁定和释放都成立，但**舵机回位时挡块必须扫回原位**，
而托板已经翻下、短杆正抬在扫掠弧内，必然被打到。
把挡块往下偏转让它躲开，又会扫过短杆本身。

**结论**：这是"平面内摆动"的固有矛盾 —— 挡块的往返路径与托板的运动路径重叠。

### v3 竖直销轴插通孔：销轴会蹭着耳板走

**做法**：耳板开一个**通孔**，销轴插进去；舵机转开抽出销轴。

**失败原因**：销轴要从孔里退出来，就必须**穿过耳板的板厚区**。
按 3° 步长扫 0~90°，销轴在 **21°~48°** 区间一直压在耳板实体上。

**表现**：舵机转到位了，但销轴卡在耳板里磨着，推不动托板。
用户看到的是"舵机动了但托板不翻"。

**结论**：必须让销轴沿**开口**滑出，而不是从孔里"拔"出来。

### v4（采用）：开口缺口 + 倒扣圆盘

两处修正同时解决了前三个问题：

| 修正 | 解决什么 |
| :--- | :--- |
| 通孔 → **开口缺口** | 销轴沿开口直接滑出。扫描显示 **0.5°** 起就完全离开耳板 |
| 光销轴 → **加倒扣圆盘** | 挡住竖直逃逸（见下） |

## 五、最隐蔽的一个坑：竖直销轴挡不住竖直逃逸

这是整个设计里最容易漏掉的一点，值得单独讲。

**一根竖直销轴插在水平板的孔里，只能约束板的平面内运动。**

看起来这样：
```
    销轴 │
         │  ← 挡住左右移动
    ═════╪═════   水平板
```

但托板不是平移，是**绕铰链旋转**。旋转时，耳板那一点的位移方向是**切向**，
而切向几乎垂直于半径向量。

```
        铰链 ●──────────── 耳板（半径近水平）
              ╲
               ╲  切向 = 运动方向（近竖直！）
                ↓
```

因为半径向量接近水平，切向就接近竖直。**所以耳板的运动几乎全是往上**。

结果：销轴只挡水平，托板可以从销轴上方直接"滑脱"。
**销轴一点都挡不住。**

**倒扣圆盘就是为这条加的**：它 Ø12 比缺口 Ø5.9 大，悬在耳板上方 0.1 mm。
托板想往上逃，耳板顶面就顶在圆盘下表面上，被挡住。

```
   托板想往上逃 ↑
        ┌────────┐  ← 倒扣圆盘 Ø12（悬在耳板上方）
        │  ╔══╗  │
    ════╧══╬══╬══╧════  耳板（被圆盘下表面挡住）
           ║销轴║
```

**这也是为什么圆盘必须是独立零件**：它比缺口大，一体打印的话耳板装不进去
（销轴没法穿过缺口）。所以圆盘单独打印，最后用 M2 螺丝拧到销轴顶端。

## 六、为什么缺口开在板边

这一点容易被当成"省事"，其实是必然。

| 方案 | 销轴退出路径 | 结果 |
| :--- | :--- | :--- |
| 通孔（孔四周都是料） | 必须穿过板厚区 | 21°~48° 卡死 |
| **开口缺口（孔开在板边）** | 沿开口滑出，不碰料 | 0.5° 即脱离 |

几何上，销轴的摆出圆弧与耳板的包围范围必然相交（因为销轴绕的圆心就在耳板附近）。
**只有让缺口朝外开口，销轴才能"走出去"而不是"穿过去"。**

配套的另一个改动：铰链从 y=4 移到 y=14。
原设计耳孔几乎贴着铰链（0.5 mm），力臂几乎为零，销轴要承受上百倍的放大力。
现在力臂 10.5 mm，受力降到 1/20 量级。

## 七、尺寸链（装配时最容易错）

Z 向从下往上堆叠，每一层都由上面的参数推出来：

| z 范围 | 部件 | 关键约束 |
| :--- | :--- | :--- |
| 0 ~ 3 | 支架底板 | — |
| 3 ~ 25.5 | 舵机机身 | — |
| 25.5 ~ 28.5 | 摇臂 | — |
| 28.5 ~ 34.5 | 销轴柱段 | 穿过耳板全厚 |
| 30.9 ~ 34.4 | 耳板 | 底面必须高于摇臂顶（28.5） |
| 34.5 ~ 35.35 | 倒扣圆盘 | 底面贴耳板顶面（间隙 0.1），顶面低于托板底（35.5） |
| 35.5 ~ 39.5 | 托板 | — |

**三处必须同时满足的约束**（`verify_geometry.py` 会自动检查）：

1. 销轴柱段要穿过耳板全厚（否则半孔咬合，一受力就脱）
2. 圆盘底面与耳板顶面间隙 0~0.25 mm（大了托板会先翘起一段才被挡住）
3. 圆盘顶面要低于托板底面（否则任何转角都磨托板）

**注意第 1 和第 2 之间的一个陷阱**：不能要求"销轴顶端高出耳板 0.3~2.0 mm
**并且**圆盘贴住耳板顶面" —— 因为销轴顶 = 圆盘底面，这两个量恒等，
不可能同时成立。我最初就写错了这条，被自检脚本报出来。

## 八、失效安全

**方向选对了，失效才会安全。**

弹簧把摇臂压在锁定位。断电时：
- 舵机失力 → 没有保持力
- 弹簧仍顶住 → 摇臂留在锁定位
- 销轴还在缺口里 → 托板锁死 → 救生圈不掉

```
断电前            断电后
舵机保持在锁定位    舵机失力、自由
   ↓                 ↓
靠电保持           靠弹簧保持   ← 这才是失效安全
```

**如果没有弹簧会怎样**：掉电后销轴在缺口里是"自由"的，水流、振动、
船体倾斜都可能让它转开。载荷自己掉进水里 —— 而且是在你最不希望的时候。

所以弹簧不是"让装配更紧"，是**安全装置**，不能省。

## 九、设计上的取舍（如实记录）

| 决定 | 代价 | 为什么还是这么选 |
| :--- | :--- | :--- |
| 用单一舵机 | 载荷上限 375 g | 项目只有这个执行器；实际救生圈 100~300 g，够用 |
| 不用刚性自锁 | 剧烈撞击理论上可能顶开 | 加弹簧插销会显著增加复杂度；拉力承受 30~50 N 已远超需求 |
| 托板前端伸出船外 30 mm+ | 占用船头空间 | 否则救生圈落在船帮上，滚回船里 |
| 圆盘用 M2 自攻螺丝 | 螺丝是失效点 | 拔出力 30~50 N，对 300 g 载荷有 4 倍余量 |
| 缺口开口朝后 | 只能单向锁定 | 载荷方向固定（船前进 + 重力），够用 |

## 十、验证手段

这套设计不是"画完看着对"就交的，有三道自动检查：

| 脚本 | 查什么 | 抓住过什么 |
| :--- | :--- | :--- |
| `verify_geometry.py` | 静态尺寸链：间隙、插入深度、对中、圆盘是否盖得住缺口 | 我写错的"销轴露出 0.3~2.0 mm" 与"圆盘贴耳板"冲突 |
| `check_pin_sweep.py` | **运动路径**：销轴摆出是否蹭耳板 + 竖直逃逸 | v3 的 21°~48° 卡死；倒扣圆盘的必要性 |
| `build.ps1` | 网格合法性（`Simple: yes`）+ 导出 STL | 圆盘开口槽把零件劈成两半 |

**为什么必须有路径扫描**：通孔方案的静态尺寸全部正确 —— 间隙对、行程够、
插入深度也够 —— 但它动不了。静态检查永远发现不了这类问题。

改任何参数后按顺序跑：

```powershell
python verify_geometry.py
python check_pin_sweep.py
pwsh -File build.ps1
```

## 十一、还能怎么改进

按投入产出排序：

1. **换成 MG996R**（约 10 kg·cm）。载荷上限能到 1 kg 以上。
   注意轴位置不同（`SHAFT_OFF` 要改成约 14 mm），支架和销轴位置都要跟着动。
2. **加弹簧插销做二次锁**。断电时弹簧顶出插销，即使舵机被反驱也不会脱扣。
   代价是多一个零件、一条线。
3. **托板加防滑纹/凹槽**。现在靠前唇挡，倾斜角度大时载荷可能侧滑。
4. **释放次数回传**。现在只能看船端串口日志，因为 `BoatToGround` 结构体
   必须恰好 32 字节才能和 Arduino 版兼容，没有空隙可加字段。
