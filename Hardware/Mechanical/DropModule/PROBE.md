# 悬挂方案 · 验证件说明

> 目的：**5 分钟、不用舵机**，验证一件事 ——
> 挂环套在横杆上，销子抽出后能不能自己滑出去。
>
> 这一步不通过，整个悬挂方案就不用做了。

---

## 为什么先做这个验证

悬挂方案和托板方案有一个根本区别：

| | 托板方案 | 悬挂方案 |
| :--- | :--- | :--- |
| 释放后 | 托板翻下，**重力必然**让救生圈滑落 | 挂环沿斜面滑动，**依赖摩擦系数** |
| 失效模式 | 几乎不可能失效（翻下去就掉了） | 可能因为摩擦/卡滞**滑不出去** |
| 纸面可信度 | 高 | 中 —— 取决于挂环材质和杆面粗糙度 |

所以托板方案可以直接打印装配，悬挂方案必须先验证"滑不滑得出去"。

---

## 三个零件

| 文件 | 尺寸 | 说明 |
| :--- | :--- | :--- |
| `stl/probe_boom.stl` | Ø8 × 90 | 横杆，距一端 15 mm 处有 Ø5.6 竖直销孔 |
| `stl/probe_loop.stl` | 内径 Ø22，截面 Ø4 | 挂环（模拟救生圈上的软绳/钢丝圈） |
| `stl/probe_pin.stl` | Ø5 × 33 | 销子，顶端有捏头 |

打印建议：全部 25% 填充、0.2 mm 层高即可。**杆的圆周表面尽量光滑**
（打印层纹会增大摩擦，这本身也是要验证的一项）。

---

## 验证步骤

### 准备

1. 打印三个件（约 1 小时）
2. 找一根橡皮筋或绳子，模拟救生圈重量（挂上 100~300 g 的东西）

### 测试

| 步骤 | 操作 | 应看到 |
| :--- | :--- | :--- |
| 1 | 挂环套到杆上，推到销孔靠里的位置 | 挂环能自由滑动，不卡 |
| 2 | 销子从上方插进销孔 | 挂环被挡住，推不出去 |
| 3 | 在挂环上挂 150 g 重物，把杆**倾斜 35°**（销孔端朝下） | 挂环压在销子上，不滑 |
| 4 | **快速抽出销子** | 挂环应**自己加速滑出**，约 0.2 秒内从杆端掉下 |

### 判定

| 结果 | 结论 |
| :--- | :--- |
| 挂环顺畅滑出 | **方案可行**，继续做整机 |
| 滑出但很慢（>1 秒） | 可行但余量小。要把倾角加大到 45°，或换更光滑的杆面 |
| 卡住不动 | **方案不可行**。原因通常是摩擦太大或挂环变形卡在杆上 |

---

## 如果卡住了，先试这三件事

按成本从低到高：

1. **加大倾角**。把杆倾斜到 45° 甚至 60° 再试。
   自锁角 = atan(μ)。μ=0.35 时是 19.3°，但打印层纹可能让实际 μ 到 0.5
   （自锁角 26.6°）。45° 能覆盖大多数情况。

2. **换挂环材质**。软绳会在杆上摊开、增大接触面积和摩擦；
   硬质钢丝圈（或金属开口销弯成的环）滑动性好得多。
   **建议直接用金属挂环**，这也是最终方案该用的。

3. **给杆包一层光滑材料**。热缩管、胶带都能显著降摩擦。

---

## 为什么倾斜 35° 是这么来的

```
挂环沿斜面下滑的条件：tanθ > μ
  μ = 0.35（尼龙对 PLA，保守值）
  自锁角 = atan(0.35) = 19.3°

取 35° -> 安全余量 15.7°
即使 μ 翻倍到 0.6（自锁角 31°），35° 仍能滑出，只是慢

沿杆加速度：a = g(sinθ - μcosθ)
  35° 时 a = 2.81 m/s²
  滑完 50 mm 用时 0.19 s —— 是"加速滑出"，不是"靠晃动碰运气"
```

这个余量是**算出来的，不是拍的**。35° 不是随便定的数字。

告诉我结果，我会做完整机构：

```
   舵机摇臂
      │  ← 平时托住悬臂内端

   │MG90S│
   └─────┘
```
