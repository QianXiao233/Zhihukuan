# STM32 RTU 模拟调试器

一个纯前端的本地调试工具，用来代替水库现场的 STM32 采集板：

- 按固定间隔向 `rtu/status` 上报水位、液温、pH、ORP 和 6 路闸门状态
- 订阅 `rtu/control`，接收平台下发的闸门开关命令，更新状态并回传上报帧
- 支持自动漂移、随机扰动、场景预设、空帧心跳、手动注入控制报文
- 所有报文都会显示在右侧日志里，方便排查前端 / 后端 / MQTT 链路

## 快速开始

1. 双击 `index.html`，或双击 `start-simulator.cmd`。
2. 在「连接配置」里填写 Broker：
   - 线上：`wss://platform.zhka.qianxiao.xin/mqtt`
   - 本机 EMQX：`ws://127.0.0.1:8083/mqtt`
3. 点击「连接 Broker」。
4. 保持「自动上报」开启，平台监控页会在下一帧收到数据。
5. 在平台上点击闸门开关，右侧日志会出现 `RX rtu/control`，闸门状态会自动更新并立即回传一帧状态。

> 连接线上 Broker 时会弹窗确认，因为模拟数据会写入真实平台，可能触发阈值告警、推送和落库记录。

## 协议

### 数据上报

主题：`rtu/status`

```json
{
  "level": 0.85,
  "temp": 22.5,
  "ph": 7.2,
  "orp": 120,
  "relay": [0, 0, 0, 0, 0, 0]
}
```

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| `level` | 水位 | 单位 m，缺测传 `null` |
| `temp` | 液温 | 单位 ℃ |
| `ph` | pH | 无量纲 |
| `orp` | ORP | 单位 mV |
| `relay` | 6 路闸门 | 1 = 开，0 = 关，固定 6 项 |

后端会把四项监测值全为 `null` 的帧当作 RTU 心跳，不落库、不做阈值判断。

### 闸门控制

主题：`rtu/control`

```json
{"cmd":"relay.set","relay":1,"state":1}
```

```json
{"cmd":"relay.all","state":0}
```

- `relay.set`：控制单路闸门，`relay` 取 1~6，`state` 取 0/1
- `relay.all`：控制全部闸门
- 模拟器收到命令后会延迟约 300ms 更新状态，并主动上报一帧 `rtu/status`，模拟真实 RTU 的动作回执

## 界面功能

- **传感器数据**：滑杆或数字输入修改读数；开启自动漂移后数据会缓慢波动
- **闸门状态**：直接点击闸门卡片可模拟现场手动拨闸，也会立即上报状态
- **上报控制**：立即上报、空帧心跳、暂停自动上报
- **场景预设**：正常水情、超汛限、水质异常、六闸全开/全关
- **回环测试**：向当前控制主题发布一条 `relay.set`，验证模拟器自己的订阅链路
- **手动注入控制**：不经过 MQTT，直接验证控制报文解析
- **消息日志**：TX / RX / SYS / ERR 四类记录，可暂停和清空

## 常见问题

**浏览器连不上 `ws://127.0.0.1:8083/mqtt`**

确认本机 EMQX 已启动，并且开启了 WebSocket 监听 8083。EMQX 默认 WebSocket 路径就是 `/mqtt`。

**线上平台是 HTTPS，模拟器能连 `ws://` 吗？**

模拟器本身是本地文件或本地 HTTP 页面。如果浏览器把页面按 HTTPS 打开，`ws://` 会被混合内容拦截；此时请使用 `wss://` 地址。

**连接成功但平台没有数据**

检查两边主题是否一致，以及平台后端订阅的是不是 `rtu/status`。模拟器日志出现 `TX` 但平台无数据时，优先检查 Broker 是否同一套。

**闸门命令没有反应**

确认模拟器已订阅 `rtu/control`（连接日志里会有「已订阅控制主题」），并确认平台发布的命令字段是 `cmd: relay.set`、`relay: 1..6`、`state: 0|1`。

**打开 `file://` 页面时没有 localStorage**

部分浏览器会限制本地文件的存储。改用本地静态服务访问即可，例如在工具目录执行：

```bash
python -m http.server 8090
```

然后打开 `http://127.0.0.1:8090/`。

## 安全提示

这是调试工具，不要部署到公网，也不要在生产环境长时间保持自动上报。调试完成后请断开连接，避免模拟数据覆盖真实 RTU 数据。
